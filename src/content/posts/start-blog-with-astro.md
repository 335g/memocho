## Astro とは？

Astroは、高速なWebサイトを構築するためのモダンな静的サイトジェネレーターです。

### 特徴

- **アイランドアーキテクチャ**: 必要な部分だけJavaScriptを配信
- **多様なUIフレームワーク**: React、Vue、Svelteなどを組み合わせ可能
- **Content Collections**: Markdownコンテンツを型安全に管理

```bash
npm create astro@latest
```

まずは上記のコマンドでプロジェクトを作成してみましょう。
